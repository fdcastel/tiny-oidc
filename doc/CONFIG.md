# Configuration

Generated by `pnpm gen:config` from the schemas in `src/env.ts` (TIO-CFG-005). Do not edit by hand; CI fails when this file is stale.

## Environment variables

Set in `wrangler.jsonc` (`vars`), by the Deploy-to-Cloudflare form, or by the deploy environment for staging and production (spec §12.2).

| Name | Type | Default | Description |
|---|---|---|---|
| `ISSUER` | string | required | Issuer URL of this deployment: `https` with no query or fragment (an optional path prefixes every endpoint). `http://localhost:<port>` and `http://127.0.0.1:<port>` are accepted for local development. |
| `RP_ID` | string | required | WebAuthn relying-party id: a registrable domain equal to or a parent of the ISSUER host and of every WebAuthn origin. |
| `RP_NAME` | string | required | Human-readable name shown by authenticators. |
| `BUNDLED_LOGIN_APP` | `"true"` \| `"false"` | `"false"` | `true` serves the reference login app under `/login/` and defaults `login_url` and `login_origins` to it (§7.9). |
| `LOG_LEVEL` | `"debug"` \| `"info"` \| `"warn"` \| `"error"` | `"info"` | Minimum level of structured log lines. |
| `DO_JURISDICTION` | `""` \| `"eu"` \| `"fedramp"` | `""` | Durable Object jurisdiction for every user and interaction object; empty for none. Fixed at bootstrap: a later change is refused, because objects made under one jurisdiction cannot be found from another (TIO-CFG-006). |
| `VERSION` | string | unset | Build identifier reported by `/api/v1/health`; set by the deploy script from the commit sha. |

## Secrets

Worker secrets (`wrangler secret put`, the Deploy form, or `.dev.vars` locally). `pnpm gen:secrets` prints fresh values.

| Name | Required | Description |
|---|---|---|
| `MASTER_KEYS` | yes | JSON object of master-key versions: `{"1":"<base64 of 32 random bytes>"}`. Generate with `pnpm gen:secrets`. |
| `MASTER_KEY_ACTIVE` | yes | Version of MASTER_KEYS used for new encryptions, for example `1`. |
| `ADMIN_BOOTSTRAP_TOKEN` | no | Bearer token accepted once by `POST /api/v1/admin/bootstrap`; may be deleted after bootstrap. |
